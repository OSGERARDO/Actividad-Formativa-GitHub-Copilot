Actividad Formativa: GitHub Copilot
# Sistema de Recomendación con GitHub Copilot

## 1. Introducción

En esta actividad se desarrolló un sistema de recomendación utilizando Python y GitHub Copilot como herramienta de asistencia para la generación del código.

El objetivo fue utilizar GitHub Copilot para crear un código inicial, probar su funcionamiento y posteriormente documentar el proceso mediante un repositorio de GitHub.

## 2. Creación del archivo Python

Primero se creó el archivo `recommendation_system.py` utilizando Visual Studio Code.

Este archivo contiene el código correspondiente al sistema de recomendación desarrollado durante la actividad.




## 3. Uso de GitHub Copilot

Para generar el código inicial se utilizó GitHub Copilot dentro de Visual Studio Code.

Se utilizó el siguiente prompt:

> Create an initial Python recommendation system for products. Use simple sample data and a recommendation function based on user preferences. Include clear comments explaining the main parts of the code.

GitHub Copilot generó una propuesta inicial de código a partir de las instrucciones entregadas. Posteriormente, el código fue revisado para comprobar su funcionamiento.



## 4. Prueba del programa

Una vez generado el código, se ejecutó el archivo `recommendation_system.py` desde la terminal de Visual Studio Code utilizando Python.

El objetivo de esta prueba fue comprobar que el programa se ejecutara correctamente y que entregara las recomendaciones correspondientes.



## 5. Control de versiones con Git

Después de finalizar el código y la documentación, se prepararon los archivos para ser registrados en el repositorio mediante Git.

Se agregaron los cambios utilizando:

```bash
git add .
```

Posteriormente se realizó el commit:

```bash
git commit -m "Agrega sistema de recomendacion con GitHub Copilot"
```

Finalmente, los cambios fueron enviados al repositorio remoto mediante:

```bash
git push origin main
```

## 6. Repositorio en GitHub

El proyecto fue conectado con el repositorio remoto de GitHub:

**Actividad Formativa GitHub Copilot**

El repositorio contiene el archivo Python y la documentación correspondiente a la actividad.

## 7. Conclusión

La actividad permitió utilizar GitHub Copilot como herramienta de apoyo para la generación de código Python, además de aplicar conceptos básicos de control de versiones mediante Git y GitHub.

Se pudo crear, probar y documentar un sistema de recomendación, registrando los cambios realizados en un repositorio remoto.
